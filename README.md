# MCAST Website Redesign Simulation

A full-site redesign simulation for the Malta College of Arts, Science and Technology (MCAST) website, presenting the College as a modern, brand-aligned educational institution and digital campus.

## Project Purpose

The purpose of this project is to explore a redesigned visual and user experience direction for the MCAST website.

This is not the production front-end implementation. The final real website implementation is expected to be developed using WordPress.

## Design Direction and Goals

The redesign treats the MCAST website as the main digital entry point for students, prospective students, parents, staff, and other visitors.

The goal is to make the website feel modern, professional, clear, accessible, student-focused, and suitable for a higher education and vocational college.

The design should make key information easier to find, especially courses, institutes, admissions information, news, events, and student support areas. The website should feel organised and practical without forcing users to search through too many menu levels.

The main design focus is:

* clear navigation
* strong course and institute discovery
* simple search access
* visible calls to action
* mobile-friendly layouts
* accessible spacing, contrast, and readable text
* authentic campus and student-focused visuals
* consistent use of MCAST colours, typography, and branding

The overall direction is to present MCAST as a modern college and campus environment while helping users find information quickly.


## Scope

This project focuses on redesigning the MCAST website, using `<span>https://mcast.edu.mt/</span>` as the main reference.

The redesign will explore the look and structure of the main website areas, including the navigation, search, hero, main sections such as course and institute sections, news/events areas, and student information for the homepage, and footer.

## Workflow

This project uses a design-assisted workflow.

The main tools are:

* Google Stitch for early website design generation, layout exploration, and visual simulation.
* Figma for layout sketching, visual refinement, and design structure where needed.
* ChatGPT for design reasoning, content planning, prompt improvement, and redesign guidance.
* GitHub Copilot for assistance when simulation files need code adjustments.
* GitHub for version control, documentation, screenshots, and design progress tracking.

The design may include HTML, CSS, Tailwind CSS, and JavaScript files generated or adjusted during the simulation process.
